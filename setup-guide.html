TikTok 脚本提取自动化 - 部署指南

基于 GitHub Actions 的全自动 TikTok 视频脚本提取 + 翻译管道

整体方案概览

  • 触发方式：GitHub Actions 每 30 分钟自动运行，无需登录
  • 提取方案：tikwm.com API 获取视频信息 + faster-whisper 语音转写
  • 翻译方案：Google Translate（免费，无需 API Key）
  • 输出格式：CSV + JSON，自动提交到 GitHub 仓库
  • 总成本：0 元（全部使用免费工具和开源项目）

项目文件结构

tiktok-script-extractor/ ├── .github/workflows/ │ └── extract.yml # GitHub Actions 定时任务 ├── input/ │ └── tiktok_links.csv # 输入：TikTok 链接列表 ├── output/ │ ├── results.csv # 输出：提取结果（CSV） │ └── results.json # 输出：提取结果（JSON） ├── src/ │ ├── main.py # 主程序入口 │ ├── extractor.py # TikTok 视频提取器 │ ├── translator.py # 翻译模块 │ └── utils.py # 工具函数 ├── .gitignore ├── requirements.txt # Python 依赖 └── README.md

部署步骤

1导出飞书表格中的 TikTok 链接

打开你的飞书表格，将包含 TikTok 链接的内容导出为 CSV 文件。

注意
脚本会自动识别包含链接的列。常见列名：url、link、链接、视频链接、tiktok_url 等。如果列名不同，脚本也会自动检测包含 "url"、"link" 或 "链接" 的列。

导出后，将 CSV 内容替换到项目的 input/tiktok_links.csv 文件中。格式示例：

url,note,category
https://www.tiktok.com/@user1/video/7234567890123456789,备注1,分类A
https://www.tiktok.com/@user2/video/7234567890123456790,备注2,分类B
2创建 GitHub 仓库
  1. 登录 github.com/new
  2. 仓库名称填：tiktok-script-extractor
  3. 选择 Public（公开仓库 GitHub Actions 免费无限时长）
  4. 勾选 "Add a README file"
  5. 点击 Create repository
3上传项目文件到 GitHub

在 GitHub 仓库页面，逐个上传以下文件（保持目录结构）：

  1. 点击 "Add file" > "Upload files"
  2. 将项目目录中的所有文件拖入上传区域
  3. 确保目录结构正确（特别是 .github/workflows/extract.yml 和 src/ 目录）
  4. 点击 "Commit changes"
提示
如果 GitHub 网页上传不方便，也可以用 Git 命令行： 
git clone https://github.com/你的用户名/tiktok-script-extractor.git
cd tiktok-script-extractor
# 复制所有项目文件到此目录
git add .
git commit -m "Initial commit: TikTok script extractor"
git push
4更新输入链接

在 GitHub 仓库中，找到 input/tiktok_links.csv，点击编辑图标（铅笔），将示例链接替换为你的实际 TikTok 链接。

每行一个链接，格式：URL,备注,分类。保存时填写 commit message 并提交。

5启用 GitHub Actions
  1. 进入仓库的 Actions 标签页
  2. 如果出现提示，点击 "I understand my workflows, go ahead and enable them"
  3. 左侧应能看到 "TikTok Script Extractor" 工作流
  4. 点击它，然后点击 "Run workflow" 手动触发第一次运行
设置完成！之后 GitHub 会每 30 分钟自动运行一次，提取新加入的 TikTok 视频脚本。

常见问题

Q: 为什么有些视频状态是 "error"？

可能原因：视频已被删除、地区限制、tikwm.com API 暂时不可用、视频下载超时。脚本会跳过错误视频，下次运行时会重试。

Q: 为什么有些视频没有脚本原文？

如果视频是纯音乐/舞蹈视频（没有人说话），Whisper 可能无法识别出文字。这种情况下 original_text 会为空，状态为 no_audio_detected。

Q: 如何修改运行频率？

编辑 .github/workflows/extract.yml 中的 cron 表达式：

  • */30 * * * * - 每 30 分钟（默认）
  • 0 * * * * - 每小时
  • */15 * * * * - 每 15 分钟

Q: 如何提高转写准确率？

编辑 src/main.py，将 Whisper 模型从 tiny 改为 base 或 small：

extractor = TikTokExtractor(whisper_model="base")  # 或 "small"

更大的模型准确率更高，但速度更慢、占用更多资源。

Q: 如何查看提取结果？

在 GitHub 仓库中打开 output/results.csv 即可查看。也可以下载到本地用 Excel 打开。JSON 格式的结果在 output/results.json。

Q: 私有仓库可以吗？

可以，但 GitHub Actions 免费额度为每月 2000 分钟。公开仓库无限制。每 30 分钟运行一次，每次约 5-10 分钟，每月约 7200-14400 分钟，建议使用公开仓库。
